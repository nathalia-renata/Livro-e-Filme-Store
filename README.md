## 📚🎬 Livros e Filmes

> DESCRIÇÃO

Esta é uma atividade feita no meu curso Técnico em Desenvolvimento de Sistemas. O objetivo é trabalhar as funções de imagens de produtos, precificação, pesquisa e mudanças de páginas.

## 🎨 Design & Código 

Foco em: 
* Manipulação de imagens de fundo
* Degradê e cor
* Botão de opções interativo
* Precificação de produtos e planos
* Linkagem para site de compras
* Site responsivo para telas(PC, celular e tablet)
* Enquadramento de imagem.

O intuito é um design e usabilidade simples, atrativo e objetivo.
